01 Logo Mark

The Voxema mark is a circle + three concentric arcs. The circle represents the meeting — a closed, bounded conversation. The arcs emanate rightward like a voice source broadcasting outward, evoking both audio waves and the classic "speaker" / signal metaphor. Together they read as voice being captured and understood. The mark is purely geometric — built from arcs and a circle — placing it firmly in the SF Symbols / system icon aesthetic that macOS professionals expect.

Use the mark without the wordmark only when the context already establishes the brand (e.g., the macOS app icon, the menu bar icon, and in-app headers after onboarding). The mark must always appear on a background from the approved color system — never on photographic backgrounds or gradients not in this guide.

02 Mark Anatomy

Circle
Center cx=38, cy=50, r=22 in 100×100 viewBox. Stroke white, no fill. Stroke-width scales with icon size (4–8px).
Arc 1 — Inner
r=30, same color as circle (white). Connects seamlessly — reads as an extension of the circle stroke.
Arc 2 — Mid
r=40, color #80b4ff (mid blue). Slightly thinner. Creates visual depth — mid distance transmission.
Arc 3 — Outer
r=50, color #4080c0 (dim blue). Thinnest. Suggests distance / reaching outward. Fades into background.
All paths use stroke-linecap: round. The mark is stroke-only — no fills, no gradients. This ensures it works as a monochrome template image (macOS menu bar) by simply changing stroke color.

07 Voice & Tone

Voxema speaks like a precision instrument. Concise, specific, and factual. Privacy is stated plainly — never marketed. No emoji in functional UI. No ellipsis in button labels.
✓ Write like this
"Meeting ready"
"whisper-medium · 769 MB"
"Audio never leaves your device."
"Permanently delete this meeting?"
"Screen Recording permission required. Open System Settings → Privacy."
✗ Not like this
"🎉 Your summary is ready!"
"We're crunching the numbers..."
"We take your privacy seriously."
"Are you sure? This can't be undone!"
"Oops! Something went wrong 😅"

08 Canonical SVG Mark

Copy this SVG directly into Xcode as a PDF asset or use it as the base for the AppIcon asset catalog. Scale stroke-width proportionally when resizing.
<!-- Voxema Mark — viewBox 100×100 — stroke-only, no fills -->
<svg xmlns="http://www.w3.org/2000/svg"
     viewBox="0 0 100 100" fill="none">
 
  <!-- Circle ring -->
  <circle cx="38" cy="50" r="22"
         stroke="white" stroke-width="5"/>
 
  <!-- Arc 1 — inner, white -->
  <path d="M 63 28 A 30 30 0 0 1 63 72"
        stroke="white" stroke-width="5" stroke-linecap="round"/>
 
  <!-- Arc 2 — mid, #80b4ff -->
  <path d="M 68 20 A 40 40 0 0 1 68 80"
        stroke="#80b4ff" stroke-width="4.5" stroke-linecap="round"/>
 
  <!-- Arc 3 — outer, #4080c0 -->
  <path d="M 74 13 A 50 50 0 0 1 74 87"
        stroke="#4080c0" stroke-width="4" stroke-linecap="round"/>
 
</svg>
